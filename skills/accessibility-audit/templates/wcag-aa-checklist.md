## Perceivable
- [ ] Text alternatives for non-text content (alt text, icon labels).
- [ ] Contrast: 4.5:1 normal text, 3:1 large text and UI components/graphics.
- [ ] Information not conveyed by color/shape/position alone.
- [ ] Content reflows at 320px width and 200-400% zoom without loss.
- [ ] Meaningful reading and content order.

## Operable
- [ ] Full keyboard operability; no keyboard traps.
- [ ] Visible, non-obscured focus indicator (Focus Not Obscured).
- [ ] Logical focus order.
- [ ] Target size at least 24x24 CSS px (prefer 44x44).
- [ ] No content flashing more than 3 times per second.
- [ ] Dragging actions have a single-pointer alternative.
- [ ] Time limits adjustable; sensor-based motion has alternatives.

## Understandable
- [ ] Clear labels and instructions; programmatic label matches visible text.
- [ ] Errors identified in text, with suggestions; prevention on critical actions.
- [ ] Consistent navigation and naming.
- [ ] Language of page and parts set.
- [ ] Consistent help placement; no redundant re-entry of information.

## Robust
- [ ] Valid, semantic markup; correct roles/states/properties.
- [ ] Name, role, value exposed for custom components.
- [ ] Status messages announced without stealing focus.

## Motion and cognitive
- [ ] Honors prefers-reduced-motion; reduced or no-motion fallback.
- [ ] No auto-playing motion that cannot be paused.
